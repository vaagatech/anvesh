1. Microservice Responsibilities

  • Engine (:3848): In-memory inverted index, vector cosine calculation, and hybrid RRF search.
  • Hub API & UI (:3849): Ingestion router, Dead-Letter inspector, user RBAC, and telemetry dashboard.
  • Spider Crawler (:3851): Web crawler with rate limiting, robots.txt compliance, and role-based authentication.
  • Indexer (:3852): High-speed streaming JSON ingestion with adaptive batch sizing.

2. Observability & Metrics

Every service exposes Prometheus /metrics scraping endpoints:

  • anvesh_search_requests_total
  • anvesh_search_duration_seconds
  • anvesh_documents_indexed_total
  • anvesh_dead_letter_records_total
