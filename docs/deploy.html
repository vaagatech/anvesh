Deploying Anvesh to Production

Automated deployment on K3s, Kubernetes clusters, Docker, and Oracle Cloud Infrastructure.

1. Deploy via Kubernetes / K3s

Apply the complete production manifest containing Engine, Spider, Indexer, Hub, Redis, HPA autoscalers, and Prometheus monitoring:

# Apply all microservices & Prometheus pod in one command
kubectl apply -f infra/k8s/anvesh-k8s.yaml

# Verify pod rollout status
kubectl get pods -n anvesh

2. Automated GitHub Actions Rollout

Pushes to main automatically trigger the backend CI/CD workflow (.github/workflows/deploy-backend.yml), which builds Docker containers into the K3s containerd cache and performs rolling updates.

3. Prometheus Metrics & Telemetry

The Prometheus pod scrapes all 4 microservices automatically:

  • Engine (:3848): http://anvesh-engine:3848/metrics
  • Spider (:3851): http://anvesh-spider:3851/metrics
  • Indexer (:3852): http://anvesh-indexer:3852/metrics
  • Hub (:3849): http://anvesh-hub:3849/hub/metrics
