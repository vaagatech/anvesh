Why Anvesh?

Engineered specifically for low-resource environments (128MB RAM pods, edge nodes, cloud microservices) while scaling to 100GB+ index corpora.

🧠

True NLP & Semantic Retrieval

Understands conversational user intent without heavy SLM/LLM runtimes. Natural language intent normalization and subword dense projections map queries like "what is my userId" directly to "username" (>0.95 cosine similarity).

⚖️

Custom Weightage Scoring

Boost document ranking at query time using conditional JSON rules. Dynamically multiply or add weights (e.g. 5x for featured items, 0.5x for archived) without costly re-indexing.

☁️

Zero-Corruption Tiered Persistence

Combines fast local SSD/NVMe volume caching with durable OCI Object Storage / S3 snapshots. Automatic SHA-256 integrity checks and instant point-in-time snapshot rollback.

🛡️

Proactive Resource Guard

Built-in circuit breakers enforce memory thresholds (75% warning, 85% backpressure) to prevent GC thrashing and container OOMs under peak load.

📈

Distributed Redis Queues & HPA

Decoupled Web Crawler (Spider) and Bulk Indexer workers scale dynamically from 1 to 5 replicas via Kubernetes HPA with distributed Redis queues and zero manual customer configuration.

📦

75MB Alpine Container

Starts in under 1 second. Zero Java/JVM runtime dependencies. Uses ~25MB of RAM per 10,000 indexed documents compared to 1GB+ for Elasticsearch.

Natural Language & RAG Semantic Search

How Anvesh achieves true semantic retrieval without requiring heavy local LLM/SLM execution.

1. Intent Extraction

Strips conversational fillers ("what is my", "how do I find") to isolate the core semantic intent.

2. Subword Dense Projection

Decomposes compound tokens (e.g. userId → user id) and projects into high-density orthogonal vector spaces.

3. Zero-LLM Cosine Recall

Produces >0.95 cosine similarity between related paraphrases ("what is my userId" ↔ "account username").

Query-Time Weightage Scoring Example

Boost document ranking using conditional JSON filter rules during search execution.

POST /v1/indexes/products/search
{
  "q": "Cloud Engine",
  "boostRules": [
    {
      "filter": { "field": "category", "equals": "featured" },
      "weight": 5.0,
      "mode": "multiply"
    },
    {
      "filter": { "field": "status", "equals": "archived" },
      "weight": 0.5,
      "mode": "multiply"
    },
    {
      "filter": { "field": "rating", "gte": 4.5 },
      "weight": 1.5,
      "mode": "multiply"
    }
  ]
}
