Developer Quickstart

Getting Started with Anvesh

Spin up a local search cluster, create an index, ingest documents, and run hybrid search in under 60 seconds.

1. Installation & Launch

You can run Anvesh via NPM or Docker:

# Option A: One-line NPX Setup
npx @vaagatech/anvesh-setup --quickstart

# Option B: Clone & Run
git clone https://github.com/vaagatech/anvesh.git
cd anvesh
npm install
npm run build
npm start

2. Ports & Endpoints

Service Port Endpoint Description
Anvesh Engine :3848 http://localhost:3848 Search & Vector REST API
Hub Control Plane :3849 http://localhost:3849 Operator Web UI & Ingestion API
Spider Crawler :3851 http://localhost:3851 Site Crawler & Web Scraper
Bulk Indexer :3852 http://localhost:3852 Streaming Bulk JSON Ingestion

3. Create an Index & Ingest Documents

# 1. Create a search index
curl -X POST http://localhost:3848/v1/indexes \
  -H "Content-Type: application/json" \
  -d '{
    "name": "products",
    "vectorDimensions": 3
  }'

# 2. Add sample documents with text and vector embeddings
curl -X POST http://localhost:3848/v1/indexes/products/docs \
  -H "Content-Type: application/json" \
  -d '{
    "id": "item-1",
    "title": "Autonomous Electric Vehicle",
    "category": "automotive",
    "price": 45000,
    "vector": [0.12, 0.85, 0.44]
  }'

4. Execute a Hybrid Search Query

curl -X POST http://localhost:3848/v1/indexes/products/search \
  -H "Content-Type: application/json" \
  -d '{
    "q": "electric car",
    "vector": [0.10, 0.80, 0.40],
    "mode": "hybrid",
    "limit": 10
  }'
