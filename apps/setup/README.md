# Anvesh Setup

Lightweight bootstrap CLI for local Anvesh stacks.

```bash
npx @vaagatech/anvesh-setup init
npx @vaagatech/anvesh-setup doctor
npx @vaagatech/anvesh-setup print-services
```

Creates `.anvesh/` directories, `.env.anvesh`, and a starter spider config. Does not replace Docker/K8s — it makes local multi-app setup straightforward.
