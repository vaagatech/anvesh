# Anvesh Hub

Optional management UI for [Anvesh](../README.md). The search API works fully without Hub.

```bash
# from repo root
npm start                 # API :3848
cd hub && npm i && npm run dev   # Hub :3849
```

Open http://127.0.0.1:3849 — leave API base blank to use the Vite proxy, or point at a remote Anvesh URL.
